# Map attribution

Hero outline and offline country outline: Natural Earth 1:50m Admin 0 Countries, public domain.
https://www.naturalearthdata.com/about/terms-of-use/
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

Country geometry extracted without boundary edits; projected to SVG for the hero. Natural Earth boundaries are generalized contextual cartography, not a legal boundary reference.

Street basemap: OpenStreetMap Standard tiles. Tactical view applies a display-only monochrome filter. Attribution is displayed within the map. Map tiles need an internet connection; the country outline and demo markers remain available when tiles fail.
https://www.openstreetmap.org/copyright
https://operations.osmfoundation.org/policies/tiles/

Geography is separate from thermal intelligence: all displayed hotspots, classification and risk are simulated.
